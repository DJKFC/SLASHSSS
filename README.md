# SLASHSSS

Бесконечный 2D-слэшер для Android в духе Devil May Cry: 5 оружий, ~80 приёмов, счётчик крутости D → SSS, бесконечные волны.

## Скачать
Каждый пуш в `main` собирает APK через GitHub Actions и выкладывает его в релиз **latest**:
https://github.com/DJKFC/SLASHSSS/releases/tag/latest — файл `SLASHSSS.apk`. Новые сборки ставятся поверх старой.

## Управление (горизонтально)
- Левая половина экрана — плавающий джойстик.
- **АТК** — лёгкая атака, **СИЛ** — сильная. Наклон джойстика в момент удара (→ ↑ ↓) меняет приём.
- **ПРЫЖОК** (двойной; у врага — шаг по врагу), **РЫВОК** (неуязвимость, уворот в момент удара = JUST DODGE).
- **СМЕНА** или тап по иконкам оружия сверху. Смена посреди комбо даёт бонус стиля.
- **ЯРОСТЬ** — копится от стиля, ×1.5 урон и скорость на 10 секунд.

## Оружие
Катана, Двуручник, Кастеты, Коса, Цепь — у каждого своя цепочка АТК, «паузное» комбо (`АТК АТК … АТК`), приёмы с направлениями, воздушные комбо и пике. Полный список — в игре, кнопка «ПРИЁМЫ».

## Враги
Рядовые, бегуны, щитоносцы (щит пробивают сильные атаки и подбросы), летуны, стрелки (пули можно отбивать), громилы с бронёй и элита каждые 5 волн. Каждые 3 волны — выбор усиления.

Чистый Kotlin + Canvas, без движков и библиотек.
